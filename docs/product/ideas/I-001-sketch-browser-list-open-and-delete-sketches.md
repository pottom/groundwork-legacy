Today the bar above the board can only open, create and rename a sketch; deleting means removing the .excalidraw file by hand. A sketch browser would list every sketch (name, last change, maybe a thumbnail, its links and threads) and delete one, taking its threads file and links along. Also a 'groundwork sketch delete <name>' command.
